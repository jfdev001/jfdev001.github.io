> Train your listening skills by transcribing real speech from YouTube videos.

`lingua-loop` is a single-page web application designed to improve language listening skills through active transcription. It is based on a transcription-first learning approach where users repeatedly listen to short audio segments and attempt to write down what they've heard.

It uses Gestalt pattern matching to compare user attempted transcriptions
against the the YouTube transcript ground truth.

See [jfdev001/lingua-loop](https://github.com/jfdev001/lingua-loop).
